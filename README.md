# Sadar Dipalak, Sadar Dibakar, Sadar Dimiskinkan

**Solidaritas untuk keadaan Indonesia hari ini.**

<sub><i>tiga jari: kesadaran, solidaritas, harapan</i></sub>

</div>

---

Tiga kalimat itu bukan slogan. Itu cermin yang telanjur kita lihat tiap hari, tapi jarang kita sebut namanya.

- **Sadar dipalak** — kekayaan alam, anggaran, dan ruang hidup rakyat terus diambil untuk kepentingan segelintir pihak.
- **Sadar dibakar** — hutan, lahan, dan masa depan generasi muda dikorbankan demi keuntungan jangka pendek.
- **Sadar dimiskinkan** — kemiskinan bukan takdir, melainkan hasil kebijakan yang tidak berpihak pada rakyat.

Sadar bukan berarti menyerah. Sadar berarti berhenti pura-pura tidak tahu. Dan selama masih ada yang sadar, masih ada yang bisa berdiri bersama.

Tiga jari diangkat: satu untuk kesadaran, satu untuk solidaritas, satu untuk harapan.

## 🧩 Ringan CMS

> **Headless CMS super ringan** — dibangun dengan **PHP native procedural**, tanpa framework besar dan tanpa dependency eksternal. Arsip rilisnya dijaga tetap **di bawah 1 MB**.

Cocok dipakai sebagai backend headless untuk frontend modern (Astro, Next, Hugo), lengkap dengan admin dashboard server-rendered.

**Yang ada di dalamnya:**

- **Content type builder** — definisikan field sendiri (ala ACF) tanpa mengubah kode; setiap tipe otomatis jadi endpoint REST `/api/v1/{slug}`.
- **Multi-role** — `superadmin`, `editor`, `viewer`, dengan audit log untuk aksi sensitif.
- **Media library** — unggah, kompresi gambar otomatis, dan offload ke R2/S3-compatible.
- **Taksonomi lintas content type** — kategori/tag hierarkis, relasi many-to-many.
- **API key & JWT** — key di-hash SHA-256, scope `read` / `read_write`, bisa dirotasi.
- **Webhook SSG** — POST bertanda tangan HMAC SHA-256 ke build hook Astro/Next/Netlify/Cloudflare, dengan retry dan log delivery.
- **Import dari WordPress (WXR)** — termasuk meta ACF, unduh media, dan anti-duplikat.
- **Update dari dashboard** — verifikasi checksum SHA-256, backup otomatis, migrasi DB.

**Persyaratan:** PHP 8.1+, MySQL 8 / MariaDB 10.4+, Apache dengan `mod_rewrite` atau Nginx.
